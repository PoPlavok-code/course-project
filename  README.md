## Реализованный функционал (Домашнее задание: Оптимизация работы с классами)

В рамках данного этапа разработки проекта "Магазин" были реализованы следующие улучшения:

- **Наследование**: Созданы классы-наследники `Smartphone` (Смартфон) и `LawnGrass` (Трава газонная) от базового класса `Product` с добавлением специфичных атрибутов (модель, память, цвет, страна-производитель, срок прорастания и т.д.).
- **Магические методы**: Доработан метод `__add__` для сложения товаров. Теперь сложение разрешено только для объектов одинаковых классов. При попытке сложить разные классы (например, смартфон и траву) выбрасывается исключение `TypeError`.
- **Инкапсуляция и защита типов**: Метод `add_product` в классе `Category` теперь защищен с помощью `isinstance()`. В категорию можно добавить только объект класса `Product` или его наследников, что предотвращает добавление посторонних типов данных.
- **Тестирование**: Написан набор unit-тестов с использованием `pytest` для проверки новой функциональности (создание объектов, сложение, защита методов). Все тесты успешно проходят.
